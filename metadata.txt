description=A QGIS plugin for bitemporal analysis of surface water quality using remote sensing indices. Supports Chlorophyll-a (NDCI, 2-Band, Moses, Ensemble), Turbidity (NDTI, Dogliotti), CDOM, Secchi Depth, Trophic State Index (TSI), NDWI, and MNDWI. Classifies water quality parameters based on peer-reviewed thresholds and detects class-level changes between two time periods.

about=BiWQA (Bitemporal Water Quality Analyzer) was developed with the assistance of DeepSeek AI and Claude AI (Anthropic).

	BiWQA enables quantitative assessment of inland water body conditions using
	Sentinel-2 derived raster indices. The plugin accepts two temporal raster
	inputs per index (Time 1 and Time 2), applies scientifically validated
	classification thresholds, computes a pixel-level bitemporal change map,
	and summarizes the results in tabular and chart form. Outputs (classified
	layers and change maps) are automatically added to the QGIS project.
	The tool is designed for limnologists, environmental engineers, and GIS
	practitioners working with lakes, reservoirs, and river systems.

    Supported indices:
    - Chlorophyll-a: Ensemble, NDCI (Mishra & Mishra 2012), 2-Band (Gitelson et al. 2008), Moses (Moses et al. 2012)
    - Turbidity: NDTI, Dogliotti (Dogliotti et al. 2015)
    - CDOM / Colored Dissolved Organic Matter
    - Secchi Disk Depth (SDD)
    - Trophic State Index (TSI - Carlson 1977)
    - NDWI / MNDWI water extent indices

    Workflow:
    1. Load Time-1 and Time-2 raster files for each index
    2. Run the bitemporal change analysis
    3. Inspect statistics and change matrix in the results panel
    4. Export results as CSV or view classified layers directly in QGIS

    1.1.0 (2026)
    - Renamed to BiWQA - Bitemporal Water Quality Analyzer
    - QGIS 4.0 full compatibility (PyQt6, Qgis.MessageLevel enum, exec())
    - Configurable pixel size (QDoubleSpinBox)

    - Provenance JSON export (ISO 19115-inspired) alongside CSV results

    - Vectorized change-matrix (np.bincount) -- up to 100x faster
    - uint16 change-map (halved memory vs int32)
    - Weighted ensemble helper for Chl-a (inverse-variance weighting)

    - Initial public release as Water Quality Temporal Change Analyzer
    - Multi-index temporal change analysis (Chl-a, Turbidity, CDOM, Secchi, TSI, NDWI, MNDWI)
    - Pixel-level change map generation and QGIS layer integration
    - Change statistics table with area (km2) and percentage summaries
    - CSV export functionality
